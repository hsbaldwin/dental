W치과의 화면은 **건강한 입속의 색과 모양**으로 만든다. 깨끗한 법랑질의 흰 바탕, 상쾌한 민트, 건강한 잇몸의 분홍, 믿음을 주는 틸. 모서리는 치아의 머리(치관)처럼 위가 더 둥글다. 이용객에는 60대 후반 어르신이 많으므로, 모든 규칙은 "처음 보는 어르신이 한 번에 알아볼 수 있는가"를 먼저 따진다.

## 말투 (콘텐츠 원칙)

- 존댓말, 짧은 문장, 쉬운 우리말. "~합니다 / ~드립니다", 챗봇은 "~해요 / ~드릴게요".
- 영어와 전문용어를 화면에 쓰지 않는다. LIVE → **실시간**, Reception → **접수 데스크**, 슬롯·타임 → **자리**, 진료X → **진료 없음**. 치식 번호(#36)는 반드시 우리말 풀이를 함께: "#36 = 아래 왼쪽 첫째 큰어금니".
- 시각은 **오후 2:30**처럼 오전·오후로. 문자 메시지는 **오후 2시 30분**. `14:30`은 직원 화면에만.
- 진단·치료 효과·최고·최저가를 말하지 않는다(의료법 제56조). "정확한 진단은 검사 후 원장님이 설명해 드립니다"를 붙인다.
- 비용은 숫자로 숨김없이: "1,100,000원 · 1개". 할인·이벤트 표현 금지.
- 이모지와 느낌표를 쓰지 않는다.

실제 문구 예: "치료하기 전에 계획서부터 보여드립니다." / "병원에서 예약을 확정했어요. 11월 5일 (목) 오후 2:30" / "만 65세 이상이신가요? 임플란트(평생 2개)와 틀니(7년마다)에 건강보험이 적용됩니다."

## 색

| 쓰임 | 토큰 | 규칙 |
|---|---|---|
| 바탕 | `enamel` | 모든 페이지. 순백 대신 아주 옅은 민트빛 흰색. |
| 올라온 면 | `enamel-raised` | 카드, 대화창, 입력칸. |
| 진료 기록 | `dentin` + `dentin-ink` | 치료계획서처럼 '종이'로 보여야 하는 것만. 일반 카드에 쓰지 않는다. |
| 글자 | `ink`, `ink-muted` | `ink-muted`보다 연한 글자는 없다. |
| 주요 행동 | `teal` + `on-teal` | 예약하기, 선택된 날짜·시간, 포커스 링. 한 화면에 꽉 찬 `teal` 버튼은 하나. |
| 실시간·정상 | `live` (+ `mint-soft` 상자) | 병원 장부에서 온 값에만. 항상 글자와 함께("진료 중", "실시간"). |
| 상쾌함 | `mint` | 장식 면만. 밝은 화면에서 대비가 낮아 글자·의미 있는 점에 쓰지 않는다. |
| 돌봄 | `gum`, `gum-ink`, `gum-soft` | 어르신 건강보험 안내, 원장 약속처럼 '돌봐 드린다'는 순간에만. 한 화면에 한 곳. |
| 주의 | `warn`, `warn-soft` | 점심시간, 접수 잠시 중단, 미내원, 오류. 빨강은 쓰지 않는다. |

- 상태는 색만으로 구분하지 않는다. "접수 중 / 점심시간 / 오늘은 진료가 없는 날 / 온라인 접수 잠시 중단"을 글자로 쓰고, 색은 `live`(정상)와 `warn`(주의) 두 가지만 쓴다. 둘은 밝기 차이로도 구분된다.
- 모든 글자 색은 표에 적힌 면 위에서 두 테마 모두 4.5:1 이상이다(각 토큰 설명에 수치). 입력칸·선택 버튼 테두리는 `line-strong`(3:1 이상), 장식 구분선만 `line`.
- 포커스 링: `teal` 3px 실선, 바깥으로 3px 띄움. 모든 버튼·링크·입력칸에.

## 글자

- 제목은 `display`·`title`·`heading`(Hahmlet), 본문은 `lead`·`body`·`label`·`caption`(IBM Plex Sans KR), 예약번호와 금액은 `code`·`figure`(IBM Plex Mono).
- 본문은 `body`(17px)보다 작게 쓰지 않는다. 가장 작은 글자는 `caption`(14px)이고 갱신 시각·보조 설명에만.
- 한 화면에 `display`는 하나. 제목은 줄바꿈이 고르게(`text-wrap: balance`).
- 영어 대문자·자간 넓힌 소제목을 쓰지 않는다. 소제목은 `label` 굵기의 우리말.

## 모양과 간격

- **치관 모서리**: 카드와 대화창은 위 두 모서리 `radius-crown`, 아래 두 모서리 `radius-root` (`border-radius: var(--radius-crown) var(--radius-crown) var(--radius-root) var(--radius-root)`). 버튼은 `radius-md`, 칩과 상태 알약은 `radius-pill`.
- 그림자는 `shadow-lift` 하나, 대화창·실시간 현황판·치료계획서에만. 나머지 카드는 `line` 테두리.
- 누르는 것은 높이 `tap-min`(48px) 이상, 서로 `space-2` 이상 떨어뜨린다. '크게 보기'에서는 `tap-easy`(60px).
- 간격은 4px 단위 `space-*`. 카드 안쪽 `space-4`~`space-5`, 단락 사이 `space-12`.
- 옆으로 밀어야 보이는 줄(가로 스크롤)은 '크게 보기'에서 여러 줄로 펼친다.

## 실시간 표식

병원 예약 장부·데스크에서 바로 온 값에는 같은 표식을 단다: `live` 점 + "실시간" 글자 + "3분 전 업데이트"(`caption`). 값이 담긴 상자는 `mint-soft` 바탕에 `live` 점선 테두리. 장부에서 오지 않은 값(설명 문구, 예시)에는 이 표식을 쓰지 않는다.

## 크게 보기 (쉬운 화면)

어르신이 한 번 누르면 켜지는 모드. 글자·버튼 1.25배, 움직임 끄기, 7일 현황표·그래프·가로 메뉴 숨김, 큰 버튼(전화하기 · 예약하기 · 오늘 진료 · 오시는 길)을 먼저. 헤더 버튼에는 아이콘만 두지 않고 "가 크게 보기" 글자를 쓴다.

## 어르신 컴포넌트

예약처럼 여러 값을 받는 일은 **한 화면에 질문 하나**로 나눈다(쉬운 예약: 진료 → 날짜 → 때 → 시간 → 성함 → 전화번호 → 확인).

- 맨 위 `StepProgress`: "3 / 7 단계"를 글자로, 단계 이름이 붙은 막대.
- 가운데 `BigChoice`: 존댓말 질문 하나, 화살표가 있는 전체 폭 선택지. 잘 모르는 분을 위한 선택지("검진 · 상담")를 맨 위에. 고를 수 없는 것도 숨기지 않고 이유를 글자로.
- 날짜는 달력 대신 "오늘 · 11월 4일 (수) · 남은 자리 11개" 목록, 시간은 먼저 오전·오후·저녁을 고른 뒤 큰 시간 버튼(`tap-easy` 이상).
- 전화번호는 `NumberPad`(64px 버튼, 하이픈 자동). 성함만 키보드로.
- 끝은 `ConfirmSummary`: 큰 글씨 요약, 줄마다 "고치기", 큰 동의 체크칸.
- 맨 아래 `WizardFooter`: "← 이전"과 "전화로 할게요"를 늘. 닫기는 아이콘이 아닌 글자로.
- 오류는 빨간 테두리만으로 알리지 않는다. 무엇을 어떻게 고치면 되는지 문장으로(`warn`).

## 음성 안내

- 헤더 "소리로 듣기"(`VoiceGuide`)를 켜면 쉬운 예약의 질문·선택지와 챗봇 답을 읽는다. 단계형 안내에는 늘 "다시 듣기", 챗봇에는 "말하기"(지원 브라우저).
- 읽는 말은 말하듯: 시각 "오후 2시 30분", 전화번호 한 자리씩("공일공"), 요일 "수요일", 단계 "7단계 중 3단계". 화면 글자도 그렇게 읽혀도 어색하지 않게 쓴다.
- 소리는 사람이 켰을 때만. 처음 방문 안내에는 "소리로도 들을래요"를 함께 묻는다.

## 그림과 아이콘

- 로고는 `assets/Logos/w-mark.svg`: 어금니 씹는 면의 윤곽(교두)을 W로 그린 선. 색은 `teal`.
- 아이콘 세트는 쓰지 않는다. 어르신이 뜻을 짐작해야 하는 아이콘 대신 **글자 버튼**을 쓴다. 꼭 필요한 기호는 화살표(→)와 실시간 점뿐.
- 치아 색 견본(VITA 셰이드 A1·A2·A3·B1)은 심미 진료 설명에만 쓰는 고유 요소다.
- 사진은 실제 병원·의료진 사진만. 치료 전후 사진은 쓰지 않는다.

## 움직임

거의 없다. 실시간 점의 은은한 퍼짐, 값이 바뀌었을 때 한 번의 옅은 깜빡임(`mint-soft`)만. `prefers-reduced-motion`과 '크게 보기'에서는 모두 끈다.
