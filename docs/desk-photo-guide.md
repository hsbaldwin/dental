# 센터 접수 데스크 사진 촬영 가이드

센터 데스크 화면 뒤에는 그림으로 된 접수 카운터가 있습니다. 실제 사진을 넣으면 그 뒤로 **흐리게(블러) · 옅게 · 민트 톤으로** 깔려 "진짜 그 데스크 앞에 서 있는" 느낌이 납니다. 사진은 분위기만 전하고, 글자와 버튼이 늘 먼저 읽혀야 합니다.

## 무엇을 찍나
- 각 진료센터의 **실제 접수 데스크 정면**. 카운터 상판이 화면 아래 1/3쯤 오도록.
- 데스크 뒤 벽 · 조명 · 화분 같은 공간 분위기가 함께 보이게.
- 센터가 데스크를 함께 쓰면 같은 사진을 써도 됩니다(센터 색이 자동으로 덧입혀집니다).

## 찍지 않는 것
- **환자 얼굴 · 진료 장면 · 모니터 화면 속 환자 정보** (개인정보, 의료광고 심의 대상).
- 직원은 **서면 동의를 받은 경우에만**. 동의가 없으면 사람이 없는 시간에 찍습니다.
- 수상 · 인증 액자, 가격표, "최고" 같은 문구가 크게 보이는 구도 (의료광고 규정).

## 구도와 빛
| 항목 | 권장 |
|---|---|
| 방향 | 가로, 데스크 정면 눈높이(서 있는 환자 시점, 바닥에서 약 1.5m) |
| 크기 | 가로 2400px 이상, 원본 그대로 받은 뒤 아래 규격으로 저장 |
| 빛 | 진료 시간 중 실내조명 그대로. 창가 역광 피하기. 플래시 쓰지 않기 |
| 정리 | 카운터 위 서류 · 개인 물품 · 전선 치우기 |
| 색 | 보정하지 않아도 됩니다. 화면에서 채도를 낮추고 민트 막을 씌웁니다 |

## 파일 규격
- 형식: `webp` 또는 `jpg`. 가로 1600px, 200KB 안팎.
- 이름: 센터 키를 그대로 씁니다. 예) `implant.webp`, `ortho.jpg`
  (키: implant · ortho · endo · esthetic · perio · kids · tmj · checkup)
- 위치: `public/img/desk/` 폴더. 다른 사이트 주소는 받지 않습니다(보안).

## 넣는 방법
1. 사진 파일을 `public/img/desk/`에 올립니다.
2. 관리 화면 → **센터 데스크** → 해당 센터의 **접수 데스크 사진** 칸에 `/img/desk/implant.webp`처럼 적고 **데스크에 반영**.
3. 비우면 다시 그림 카운터만 보입니다. 파일이 없거나 열리지 않으면 자동으로 그림 카운터로 돌아갑니다.

## 화면에서 사진이 처리되는 방식
- 6px 흐림, 채도 75%, 투명도 32%, 위쪽은 점점 사라지게(글자 영역 보호).
- 센터 색이 섞인 옅은 막을 덧씌워 사이트 색과 맞춥니다.
- '크게 보기'에서는 절반 더 옅게. 휴대폰에서도 같은 방식.
