# W치과 공식 웹사이트 시안

`index.html` 한 파일로 된 W치과 홈페이지 컨셉 시안입니다. 브라우저로 열면 바로 볼 수 있습니다.

## 1. 조사 범위와 한계

- 이 작업 환경의 네트워크 정책 때문에 **네이버 검색(search.naver.com)과 각 치과 사이트에 직접 접속하지 못했습니다.**

## 2. 국내 치과 홈페이지에 흔한 패턴과 이 시안의 대응

| 흔한 패턴 | 문제 | 이 시안 |
|---|---|---|
| 원장 사진 + 장비 사진 슬라이더 히어로 | 어느 치과나 비슷해 보임 | 히어로에 **치료계획서 예시**를 놓아 "설명 먼저"라는 차별점을 바로 보여줌 |
| 텍스트를 이미지로 만든 배너 | 검색·접근성·모바일 가독성 나쁨 | 모든 글을 HTML 텍스트로 작성 |
| 팝업·이벤트 할인 배너 | 의료광고 심의 위험, 신뢰 저하 | 할인 표현 없음, 비급여 금액 공개 |
| 메뉴 깊이가 깊은 진료과목 페이지 | 환자는 진료명보다 증상을 앎 | **"어디가 불편하세요?" 증상 선택 → 추천 진료·소요 시간·보험 안내 → 예약 연결** |
| 오른쪽 퀵메뉴 | 모바일에서 화면 가림 | 모바일 하단 고정 바(전화 / 카카오 / 예약) |

## 3. 반영한 2026 트렌드

1. **모바일 우선** – 하단 고정 예약 바, 한 손 조작 크기 버튼
2. **투명성** – 치료계획서, 비급여 진료비 표, 건강보험 적용 조건 카드
3. **접근성** – '가+' 큰 글씨 버튼(임플란트 환자층 고려), 키보드 포커스 표시, 본문 바로가기, 시스템 다크 모드 대응
4. **실시간 정보** – 한국 시간 기준 "진료 중 · 21:00까지" 상태 표시, 오늘 요일 강조
5. **브랜드 모티프** – W를 어금니 교두(씹는 면) 윤곽선으로 그린 로고. VITA 셰이드 가이드, FDI 치식 번호(#36) 같은 치과만의 디테일
6. **예약 채널 통합** – 네이버 예약, 카카오톡 채널, 전화, 자체 폼

## 4. 오픈 전 교체할 것

- 주소·전화·사업자 정보, 원장 이름·사진·이력 (모두 `OO`, `원장 성함` 등 예시)
- 비급여 진료비 표 금액 (현재 **예시 금액**)
- 네이버 예약·카카오 채널·지도 링크 (현재 각 서비스 첫 화면으로 연결)
- 예약 폼 전송 처리 (현재는 화면에 안내만 표시하고 전송하지 않음)

## 5. 의료광고 관련 체크리스트

- 치료 후기·체험담, "최고·유일·최저가" 같은 표현은 쓰지 않았습니다 (의료법 제56조).
- 전후 사진을 추가한다면 사전 심의와 부작용 안내가 필요합니다.
- 푸터에 부작용 가능성 안내, 비급여 고지, 개인정보처리방침 링크를 넣었습니다.
- 실제 게시 전에 대한치과의사협회 의료광고 심의 대상인지 확인하세요.
